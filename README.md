# Portfolio Website

A minimalist, single-page portfolio website built with vanilla HTML, CSS, and JavaScript.

## Features

- Responsive design (mobile-first)
- Fixed navigation with scroll spy
- Mobile hamburger menu
- Hero section with CTA buttons
- About section with quick stats
- Skills grid organized by category
- Projects section with filter tabs (All/Mobile/Web/Backend)
- Experience timeline layout
- Contact form with client-side validation
- Scroll animations using Intersection Observer
- Back to top button

## Tech Stack

- HTML5
- CSS3 (Grid, Flexbox, Custom Properties)
- Vanilla JavaScript
- No frameworks or dependencies

## Getting Started

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```

2. Open `index.html` in your browser to preview

## Customization

1. Replace "Your Name" in `index.html` with your actual name
2. Add your profile photo to `assets/profile/`
3. Add project screenshots to `assets/projects/`
4. Update project links, descriptions, and tech tags
5. Update contact information (email, LinkedIn, GitHub, location)
6. Customize the skills list with your actual tech stack
7. Update experience entries with your work history

## Deployment

### Vercel (Recommended)

1. Push to GitHub
2. Connect your repository at [vercel.com](https://vercel.com)
3. Deploy automatically

### GitHub Pages

1. Push to GitHub
2. Go to Settings > Pages
3. Select source branch (main/master)
4. Your site will be live at `https://username.github.io/repo-name`
